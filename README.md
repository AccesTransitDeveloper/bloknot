# Офлайн-блокнот на Flutter

Исходный Flutter-проект находится в папке [`flutter_offline_notebook/`](flutter_offline_notebook/README.md).

В приложении есть локальные заметки, категории, поиск и системные напоминания без необходимости подключения к интернету. Инструкции по запуску, настройке Android-уведомлений и генерации иконки находятся в README проекта.
