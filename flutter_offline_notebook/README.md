# Офлайн-блокнот на Flutter

Мобильное приложение для заметок и напоминаний. Заметки хранятся локально на
телефоне; сервер и подключение к интернету не используются. Напоминания
планируются как системные локальные уведомления.

## Запуск

1. Установите Flutter SDK 3.38.1 или новее.
2. Создайте пустой проект: `flutter create offline_notebook`.
3. Скопируйте из этой папки `pubspec.yaml`, каталоги `lib/` и `assets/` в созданный проект.
4. В корне проекта выполните `flutter pub get`.
5. Создайте значки Android и iOS из предоставленной картинки: `dart run flutter_launcher_icons`.
6. Для Android скопируйте содержимое `android/app/src/main/` из этой папки
   в `android/app/src/main/` созданного проекта с заменой манифеста и добавлением
   ресурсов. Не удаляйте остальные файлы созданного проекта.
   Проверьте Gradle-настройки из `ANDROID_SETUP.md`.
7. Запустите приложение: `flutter run`.

## Что реализовано

- Создание и редактирование заметок с заголовком и текстом.
- Категории «Рабочее», «Личное» и «Идеи».
- Поиск, закрепление и удаление заметок.
- Локальное сохранение на устройстве с помощью `shared_preferences`.
- Выбор даты и времени напоминания.
- Локальные уведомления, которые не требуют интернета.
- Значок приложения из `assets/app_icon.png` для Android и iOS.
- Русский интерфейс в стиле компактной панели управления.

## Важно

Уведомления должны быть разрешены в настройках телефона. На Android точное
время дополнительно зависит от разрешения на точные будильники и ограничений
энергосбережения производителя телефона. При запрете разрешения приложение
сохранит заметку, но не сможет показать уведомление.

После обновления APK откройте приложение и нажмите «Проверить уведомления».
Для проверки планировщика установите напоминание через 2 минуты и сверните
приложение. Старые неработавшие напоминания нужно установить повторно.
Не удаляйте приложение перед установкой обновления: это удалит локальные заметки.
